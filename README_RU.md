# SetEquation

Небольшой решатель на C++17 для систем уравнений над множествами натуральных чисел. Каждое уравнение присваивает именованной переменной множество-выражение, построенное из фиксированных множеств, объединений, пересечений и попарных сумм других переменных. Решатель выполняет заданное число итераций по всей системе и выводит итоговые значения.

## Возможности

- Язык выражений над множествами:
  - фиксированные множества: `{1, 2, 3}`
  - ссылки на переменные: `A`, `B`, `C`, … (идентификаторы)
  - объединение: `|`
  - пересечение: `&`
  - попарная сумма: `+`
  - скобки для группировки
- Приоритет операторов (от высшего к низшему): `&`, `+`, `|`
- Рекурсивные и взаимно рекурсивные уравнения (вычисляются итеративно)
- Интерфейс командной строки с настраиваемыми входным/выходным файлами и числом итераций
- Полный набор тестов (выражения, парсер, вычислитель, приложение)

## Требования

- CMake ≥ 3.16
- Компилятор с поддержкой C++17 (MinGW-w64 g++, GCC, Clang или MSVC)
- CTest (поставляется с CMake) для запуска тестов

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/gcu [опции]
```

Опции:

| Опция  | По умолчанию      | Описание                             |
|--------|-------------------|--------------------------------------|
| `-f`   | `gcu_input.txt`   | Путь к входному файлу                |
| `-o`   | `gcu_output.txt`  | Путь к выходному файлу               |
| `-n`   | `30`              | Число итераций                       |
| `-h`, `--help` | —         | Вывести справку и завершить работу   |

Результат сначала записывается в выходной файл, затем выводится в стандартный поток вывода.

## Формат входных данных

Входной файл содержит по одному уравнению на строку. Пустые строки игнорируются.
Каждое уравнение имеет вид:

```text
VAR_NAME = expression
```

где `expression` строится из:

- фиксированных множеств: `{1, 2, 3}`, `{}` (пустое множество)
- имён переменных, которые создаются при первом использовании
- операторов `&`, `+`, `|`
- скобок `(` `)`

Операторы левоассоциативны и подчиняются приоритету `&` > `+` > `|`.
Переменные, на которые ссылаются в выражении, могут быть определены позже в
том же файле; система приводится к неподвижной точке за счёт итераций.

Пример (`gcu_input.txt`):

```text
A = {1, 2, 3} | (B & C)
B = (A + {1}) & {2, 3, 4, 5}
C = ({1, 2} + {3}) | (A & B) | {10}
```

## Формат выходных данных

Выход содержит все определённые в системе переменные, по одной на строку,
отсортированные по имени:

```text
A = { 1 2 3 4 5 }
B = { 2 3 4 5 }
C = { 2 3 4 5 10 }
```

## Быстрый пример

Создайте `gcu_input.txt`:

```text
A = {1, 2}
B = A | {3}
C = B & {2, 3, 4}
```

Запустите:

```bash
./build/conjuctive_unary_example -f gcu_input.txt -o result.txt -n 10
```

Консоль и файл `result.txt` будут содержать:

```text
A = { 1 2 }
B = { 1 2 3 }
C = { 2 3 }
```

### Основные классы

- **`Expression`** — абстрактный базовый класс для выражений над множествами; `calculate()` возвращает `data_t`.
- **`ConstantExpression`**, **`UnionExpression`**, **`IntersectionExpression`**, **`SumExpression`** — конкретные операции, владеющие своими операндами.
- **`VariableExpression`** — изменяемая именованная переменная; её значение — то, к чему сходится система.
- **`ExpressionProxy`** — невладеющая обёртка, разрывающая циклы владения (например, `A = A | {1}`).
- **`Parser`** — рекурсивный нисходящий парсер; строит дерево выражения и регистрирует новое `Equation` в вычислителе.
- **`Equation`** — владеет выражением и ссылается на целевую переменную; `calculate()` присваивает результат выражения этой переменной.
- **`EquationCalculator`** — владеет всеми переменными и уравнениями; `iterate()` вычисляет каждое уравнение по одному разу.
- **`VariableDictionary`** — двунаправленный словарь имя ↔ переменная, используемый парсером и принтером.
- **`ResultPrinter`** — форматирует итоговые значения переменных и пишет их в файл и/или поток.
- **`Options`** — разбор опций командной строки.
- **`Application`** — связующий код; `main()` только вызывает `Application::run()`.
